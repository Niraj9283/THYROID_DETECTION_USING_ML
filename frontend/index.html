      🔬 Model Laboratory Architectures

      • Stacking Super Learner: Multi-model meta-learner trained on 5-fold out-of-fold probability vectors to dynamically weigh base classifiers.
      • Gradient Boosted Trees (XGBoost / LightGBM / CatBoost): Histogram and symmetric split decision trees for non-linear biomarker interactions.
      • Unsupervised Autoencoder: Bottleneck neural network trained on normal endocrine profiles to detect atypical biomarker combinations via reconstruction loss.
      • Deep Tabular MLP: Multi-layer neural network with bottleneck projections for continuous feature representation learning.
